This small project tends to create a simple tool for learning and practicing chords. Right now, there isn't much functionality in it because I'm terrible at the piano and I don't want to make it too difficult at this point.

---
**WHAT YOU NEED**
-
A MIDI keyboard  
Unity 6  

The system should detect the product automatically, but if anything goes wrong, you can use MIDI Device Assigner to change the product name there.
